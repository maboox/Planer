## پوشش رابط

تصاویر `screenshots/` از خود Compose با Robolectric native graphics و Android API 35 گرفته شده‌اند. اندازهٔ اصلی ۴۱۱×۸۹۱ dp است؛ آزمون جداگانه دسترسی به اقدامات در ۳۲۰×۶۴۰ dp را بررسی می‌کند. تصاویر با ابزار مشاهدهٔ تصویر باز و خوانایی، جهت متن و کنترل‌های اصلی بررسی شده‌اند.

آزمون کامل، مأموریت را باز می‌کند، Activity را بازسازی می‌کند، حفظ همان مأموریت و پوشیده‌بودن دوبارهٔ آن را بررسی می‌کند، دور را تمام می‌کند، انتخاب همه را ثبت می‌کند، کارت‌ها را افشا و نتیجه را ذخیره می‌کند. برد مشترک و ذخیرهٔ یک‌بارهٔ نتیجه نیز بررسی می‌شود.

## هشدارهای باقی‌مانده

- `OldTargetApi`: هدف فعلی API 36 است، نه 37. پیش از انتشار بازار باید الزام روز فروشگاه بررسی شود.
- `GradleDependency`: OkHttp 5.3.2 انتخاب شده؛ نسخهٔ جدیدتر 5.5.1 به compile SDK 37 نیاز دارد. ارتقا به‌صورت یک مجموعهٔ سازگار از SDK و ابزار ساخت انجام می‌شود، نه صرفاً تغییر یک شماره.

هشدارها با baseline یا خاموش‌کردن بررسی پنهان نشده‌اند.

## چیزهایی که هنوز تأیید نشده‌اند

- اجرای واقعی روی گوشی فیزیکی؛ این نسخه برای دریافت همین بازخورد آزمایشی منتشر شده است.
- سرگرم‌کننده‌بودن و تعادل تمام مأموریت‌ها در جمع انسانی؛ تست نرم‌افزاری آن را اثبات نمی‌کند.
- درخواست پولیِ واقعی به AvalAI؛ کلید واقعی ارائه نشده و تست‌های API با پاسخ کنترل‌شده اجرا شده‌اند. شناسهٔ مدل باید در حساب کاربر فعال باشد.
- امضای خصوصی و انتشار فروشگاهی؛ کلید انتشار تنظیم نشده است. preview امضای توسعه دارد.

اسکن بدون یافته، تضمین امنیت کامل یا بی‌خطابودن AI نیست. این گزارش مربوط به کد و وابستگی‌های همین نسخه در تاریخ بالا است.
